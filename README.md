# 端末カウント

毎日の締め作業で、場所ごとの端末の台数を記録する Web アプリです。

1. 場所を選んで写真を撮る
2. 目視で数えた台数を入力する
3. 「AIに学習させる」で確定する

確定した写真と台数が学習データとして蓄積され、使うほど AI の推定が正確になります。

## 使い方

- 公開ページ: GitHub Pages（このリポジトリの Settings → Pages に表示される URL）
- スマートフォンで開き、ホーム画面に追加するとアプリのように使えます。
- 記録・写真・学習データは開いたブラウザの中（IndexedDB）に蓄積され、外部には送信されません。別の端末に移すときは、設定の「バックアップを書き出す」と「データを読み込む」を使ってください。

## AI について

- 外部の AI サービスとは連携せず、すべてブラウザの中で処理します。写真の中の端末を画像認識（TensorFlow.js / COCO-SSD）で検出して数え、写真の特徴（MobileNet）で似た写真を探します。初回だけモデルのダウンロードにインターネット接続が必要です。
- 目視の台数との差を学習して補正し、似た写真の台数からの推定も組み合わせます。どの方法が一番当たるかは蓄積したデータで自動的に検証し、成績のよい方法を採用します。

ファイルは `index.html` 1つだけで、ビルドは不要です。

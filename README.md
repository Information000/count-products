# 端末カウント

毎日の締め作業で、場所ごとの端末の台数を記録する Web アプリです。

1. 場所を選ぶと、ページ内でカメラが起動する
2. シャッターを押すと、AI が自動で台数を判定する（見つけた端末に青枠と番号が付く）
3. 合っていればそのまま確定、違っていれば目視で数えた台数に直して確定する

確定した写真と台数が学習データとして蓄積され、目視で直した差を AI が学習するので、使うほど判定が正確になります。

## 使い方

- 公開ページ: GitHub Pages（このリポジトリの Settings → Pages に表示される URL）
- スマートフォンで開き、ホーム画面に追加するとアプリのように使えます。
- 記録・写真・学習データは、このリポジトリの `count-data` ブランチの `data/` フォルダに JSON として蓄積されます（GitHub Pages の再公開は起きません）。
- 使う端末ごとに一度だけ、設定画面の「GitHubに保存」でトークンを入力します。トークンは GitHub の Fine-grained token で、対象リポジトリを count-products のみ、Permissions の Contents を「Read and write」にして作成してください。トークンはその端末の中にだけ保存されます。
- 接続前や電波がないときの記録は端末内に保存され、次の同期でまとめて GitHub に送られます。
- リポジトリが公開設定の場合、保存した写真と記録は誰でも見られます。

## AI について

- 外部の AI サービスとは連携せず、すべてブラウザの中で処理します。写真の中の端末を画像認識（TensorFlow.js / COCO-SSD）で検出して数え（写真全体と、拡大した4分割の両方を調べて重複をまとめる）、写真の小さな特徴量で似た写真を探します。モデルは最初に写真を撮ったときに読み込みます。
- 目視の台数との差を学習して補正し、似た写真の台数からの推定も組み合わせます。どの方法が一番当たるかは蓄積したデータで自動的に検証し、成績のよい方法を採用します。

ファイルは `index.html` 1つだけで、ビルドは不要です。
